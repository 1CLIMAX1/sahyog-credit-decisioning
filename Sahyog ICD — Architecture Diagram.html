Layer 1 — Capture

📱 Dealer App (Android/iOS PWA)

  • Applicant personal & income details
  • Vehicle + down payment info
  • Local field validation (age ≥18, FOIR, pincode)
  • Encrypted submission (TLS 1.3)

🪪 KYC & Consent Capture

  • Aadhaar OTP via DigiLocker
  • Document OCR (photo upload fallback)
  • Digital consent for bureau + AA pull
  • Timestamp + IP logged

🏪 Sourcing Channels

  • Dealer walk-in (160+ dealerships)
  • DSA (field agents)
  • Digital partner
  • Branch counter

📋 Application API

  • REST endpoint receives form payload
  • Idempotency key to prevent duplicates
  • Returns application_id immediately
  • Triggers enrichment pipeline async
↓ Application payload passes to enrichment ↓
Layer 2 — Enrichment

📊 Credit Bureau (CIBIL / Experian)

  • Bureau score (300–900) or -1 NTC
  • Enquiries last 6 months
  • Existing EMI obligations
  • Bureau vintage months
  • ⚠ Timeout >8s → "bureau unavailable" flag → auto-refer to officer

🏦 Account Aggregator (AA)

  • Net monthly credits (verifies income)
  • Salary regularity score
  • Existing EMI debits from bank
  • Mandatory for NTC applicants
  • ⚠ Consent refused → declared income only → refer if FOIR >50%

🚫 Fraud & Negative List

  • Sahyog internal blacklist check
  • Industry fraud consortia lookup
  • Velocity check: >2 apps in 30 days
  • Duplicate Aadhaar / mobile / vehicle
  • ⚠ Match → hard REJECT (no ML score)
↓ Enriched application passes to decision engine ↓

🔀 Decision Routing Bands

PD ≤ 0.20
✅ AUTO APPROVE
Straight-through · No officer review · ~70% of volume · Instant disbursal eligible
0.20 < PD ≤ 0.33
✅ APPROVE + FLAG
Approved with monitoring flag · Appears in collections early-warning list · ~27% of volume
0.33 < PD ≤ 0.55
⏸ REFER TO OFFICER
Pre-scored queue with top 3 SHAP reasons · Officer SLA 30 min · ~20% of volume
PD > 0.55
❌ AUTO REJECT
Reason codes sent to applicant · Grievance redressal offered · <3% of volume
SHAP Reason Codes (all decisions): Up to 3 plain-language reasons generated per decision. Displayed in dealer app + included in RBI key fact statement. Examples: "Monthly obligations exceed 65% of income" · "Limited credit history" · "Income unverified"
↓ Decisions logged → monitoring & feedback loop ↓
Layer 4 — Monitoring

📉 Score Drift (PSI)

  • Population Stability Index weekly
  • PSI >0.20 → model review alert
  • PSI >0.25 → auto-retrain trigger
  • Feature-level drift per variable

📊 Portfolio Monitoring

  • Bad rate by: channel · state · occupation · vehicle segment
  • Dealer-level monthly bad rate
  • Dealer flagged if >2σ from mean
  • Approval rate trend by cut-off

🔒 Audit Log (Immutable)

  • Every decision: input snapshot + score + reasons + operator ID
  • Officer override with mandatory reason code
  • 7-year retention
  • India data residency (AWS Mumbai / Azure Central India)

🔄 Retraining Schedule

  • Quarterly: 18-month observation window
  • Triggered: PSI >0.20 or bad rate gap >3pp for 2 months
  • Recalibration (Platt): if AUC stable but calibration drifts
  • Model versioning with rollback
